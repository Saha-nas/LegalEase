# LegalEase – AI-Powered Legal Document Generator

LegalEase is an AI-powered application that helps users generate customizable legal documents based on their requirements.

## Features

- Generate legal documents using AI
- Multiple document types
- Input validation
- Preview and edit generated documents
- Download documents as TXT
- Download documents as DOCX
- Download documents as PDF

## Technologies Used

- Python
- Streamlit
- FastAPI
- Google Gemini API
- python-docx
- FPDF
